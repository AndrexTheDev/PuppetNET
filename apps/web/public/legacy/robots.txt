#  The console is a single-page application: everything a crawler can read lives
#  behind `/legacy/` (v2 mounts the retained v1 console there), and the deep links
#  are hash fragments (`/legacy/#/q=kastelion&depth=2`), which are never requested
#  as separate URLs. There is nothing to hide and nothing to paginate, so the
#  whole deployment is open.
#
#  A `Sitemap:` line has to be absolute, and this file is committed long before
#  the deployment origin exists. `npm run emit:seo -- --origin https://console.example`
#  rewrites this file with the Sitemap line and writes the git-ignored
#  `apps/web/public/legacy/sitemap.xml`; the Pages build gate
#  `scripts/pages-build.mjs` runs the same emitter whenever the build environment
#  sets `SITE_ORIGIN`, so a configured live site carries both and the repository
#  never has to guess a hostname.
#
#  Running a private investigative deployment? Replace the Allow below with
#  `Disallow: /` and set `noindex, nofollow` in web/index.html — see
#  docs/web-console.md#hardening.
