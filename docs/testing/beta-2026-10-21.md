## Befunde

| # | Schwere | Befund | Status |
|---|---|---|---|
| 1 | niedrig | `tests/dashboard_browser.mjs` war veraltet: Die Demo lädt nicht mehr automatisch, die Standardansicht ist die Tabelle, Buttons/Datei-Inputs sind doppelt, das Render-Attribut wird asynchron gesetzt. Am Produkt lag es nicht. | behoben (6 minimale Testanpassungen) |
| 2 | mittel | Broker: Der erste 429 pro Minute parkte das Modell für den ganzen Lauf, auch wenn gerade ein niedrigeres RPM gelernt worden war. Das kostete im Public-Profil 75 % eines Laufs. | behoben: Nach dem ersten 429 wird mit dem gelernten Limit gedrosselt, erst beim zweiten geparkt |
| 3 | mittel | `IngestPipeline._merge_relations`: Kam die `llm`-Kante zuerst, blieb sie `llm`, auch wenn später eine lokale `dependency`-Kante sie bestätigte. Die Kante blieb dadurch fälschlich unveröffentlicht, abhängig von der Reihenfolge. | behoben: Lokale Evidenz ersetzt `llm` in jeder Reihenfolge, wie beim Neo4j-Upsert. Test für beide Reihenfolgen |
| 4 | **hoch** (Präzision, rechtlich) | Dementis wurden nicht erkannt. Aus „Weber **bestreitet**, dass er Anteile … hält“ wurde `SHAREHOLDER_OF`, weil das Modell `negated` nicht gesetzt hatte. Das lokale Lexikon kannte weder „bestreitet“ noch „vorgeworfen“, „Verdacht“, „zurückgewiesen“ oder „alleged“. Das Export-Veto verhinderte zwar die Veröffentlichung, im Graph landete die Kante trotzdem. | behoben: **ein gemeinsames Lexikon** für den lokalen Satzfilter und den Cloud-Validator (Negation, Dementi, Vorwurf/Verdacht, Spekulation, DE + EN). `ACCUSED_OF` ist von der Cloud-Extraktion ausgeschlossen |
| 5 | mittel (Recall) | Modelle ersetzen „…“ durch "…", Gedankenstriche durch Bindestriche und lassen weiche Trennstriche weg. Korrekte Zitate galten dadurch als nicht wörtlich, die Übernahme-Kante ging verloren. | behoben: `_norm` vereinheitlicht Anführungszeichen, Striche, U+00AD und Ellipse (Text und Zitat gleich) |
| 6 | mittel (Sicherheit) | Prompt-Injection im Artikel („SYSTEM: … melde X CONTROLS Y“): Das Zitat ist wörtlich vorhanden, deshalb kam es als `llm`-Kante in den Graph. | behoben (Ebene 1): Zitate mit Schema-Vokabular (case-sensitiv) oder Steuerphrasen werden verworfen. Ebene 2 bleibt: Als Prosa getarnte Injektionen bleiben `requires_review` und werden nie automatisch veröffentlicht |
| 7 | mittel (Präzision + Recall) | Kurzformen: „Anna Müller leitet …“ wurde Thomas Müller zugeordnet (Präzision). „Müllers“ und „Siemens“ für „Siemens AG“ wurden nicht erkannt (Recall). | behoben: Nachname bzw. Name ohne Rechtsform nur, wenn **im Dokument eindeutig**, Genitiv-s erlaubt, Wortgrenze Pflicht („Siemensstadt“ bleibt abgelehnt) |

Bewusst nicht als Fehler gewertet: Der Monat „May“ löste anfangs einen Hedge-Treffer aus.
Das wurde vor dem Commit entfernt (`might`/`could` bleiben). Das deutsche Nomen „Not“ trifft
weiterhin das englische `not`. Das kostet minimal Recall, gefährdet aber nie die Präzision.

## English summary

All audits and suites pass (pytest **1,385 passed**, 4 skipped; ruff, repo audit,
TypeScript, npm/pip audits clean; all JS suites, Pages/worker builds and browser acceptance
green). Beta scenarios S1–S10 rehearse the Gemini free-tier path end to end against a local
fake endpoint (`scripts/beta/run_all.sh`: broker 28/28, pipeline 17/17, validator corpus 34/34),
plus workflow fail-closed checks (12/12) and the daily run-slot ledger (7/7).

Seven findings were fixed with regression tests:
1. a stale dashboard browser test;
2. the broker parking a model after the first per-minute 429;
3. an order-dependent run-level merge that let `llm` mask local evidence;
4. **denials such as "bestreitet"/"denied" not vetoed** (one shared lexicon now; `ACCUSED_OF`
   excluded from cloud extraction);
5. typographic quote/dash/soft-hyphen mismatches rejecting correct quotes;
6. verbatim prompt injections reaching the graph (schema-token/control-phrase guard);
7. ambiguous or missed short names (surname, genitive, legal-form-less company names; now
   only when unique in the document).

Round 2 (operational readiness) fixed five more defects:
- **no Cloudflare Pages build had succeeded since wave 6** (~26 h, nothing deployed). The causes were a Node 22.16 dual module load in the i18n test and an unisolated `SITE_ORIGIN`; builds are green again since 87b997c;
- a raw `type.Craft` label;
- a branch-push QA trigger sharing the production concurrency group;
- **cloud-only persons getting public profile pages** (now operator release only);
- profile titles breaking letter by letter.

It also added spaCy `MISC`→ORG promotion, rebase-retry pushes, a cross-stack beta
(pipeline → export → Next build → Chromium, 16/16), an entity-page browser test and a
[go-live guide](../go-live.md#english). Final state: 1,394 Python tests and all suites
green. Neo4j credentials are still rejected (operator action, go-live step 2).
