## Befunde und Fixes (Commit `fix: retire dead gemini-1.5-flash default…`)

1. `gemini-1.5-flash` wurde von Google eingestellt (HTTP 404 auf countTokens);
   Produktions-Stufe 3 war damit still tot. Neuer Default: das live verifizierte
   `gemini-flash-lite-latest` (`DEFAULT_GEMINI_MODEL`, Workflow-Fallbacks synchron).
2. Tokenizer-Drift: Der unveränderte Produktions-Prompt zählt auf aktuellen
   Modellen 109 Tokens — der alte 100-Token-Input-Guard hätte selbst ein
   funktionierendes Modell verweigert. Guard auf 120 angehoben; das harte
   150-Token-Gesamtbudget bleibt unverändert.
3. `gemini-2.5-flash` ist für neuere Accounts gesperrt („no longer available to
   new users"); `gemini-3.8-flash` (Thinking-Klasse) überschritt selbst 60 s auf
   dem Legacy-`generateContent`-Pfad (Produktions-Timeout 15 s). Fazit:
   Lite-/Alias-Modelle für die Stufe-3-Kleinstklassifikation; `thinkingConfig`
   mit `thinkingBudget: 0` für `gemini-2.5-`/`gemini-3.x`-Präfixe; unbekannte
   Modelle weiterhin fail-closed.
4. Der Schedule-Fehlschlag des Legacy-Keep-alive (05:17 UTC, Run 39405420165,
   „Require actual database credentials") stammt aus der Workflow-Version vor
   dem PR-#6-Merge (Legacy-Secret-Namen). Mit den aktuellen Namen sind alle
   Secrets belegt; die Neo4j-Authentifizierung selbst ist dennoch defekt (s. o.).

# QA dry run 2026-10-20 — live verification of the daily ingestion pipeline

Early end-to-end integration test (before the 03:00 UTC cron) on branch
`arena/90cccbb3-puppetnet` using a temporary `verify-connections` job in
`daily_ingestion.yml` and a live probe script
(`packages/pipeline/tests/test_api_connections.py`, removed after the dry run as
planned). Triggers: `repository_dispatch` on `main` (result: publish job correctly
*skipped*, gate `ENABLE_DAILY_STATIC` not set) plus QA-branch pushes;
`workflow_dispatch` was denied to the session token (actions:write 403).

## Findings and fixes (commit `fix: retire dead gemini-1.5-flash default…`)

1. `gemini-1.5-flash` was retired by Google (HTTP 404 on countTokens); production
   stage 3 was silently dead. New default: the live-verified
   `gemini-flash-lite-latest` (`DEFAULT_GEMINI_MODEL`, workflow fallbacks in sync).
2. Tokenizer drift: the unchanged production prompt now counts 109 tokens — the
   old 100-token input guard would have refused even a working model. Guard raised
   to 120; the hard 150-token total budget is unchanged.
3. `gemini-2.5-flash` is gated for newer accounts ("no longer available to new
   users"); `gemini-3.8-flash` (thinking class) exceeded even a 60 s read timeout
   on the legacy `generateContent` path (production timeout 15 s). Conclusion:
   lite/alias models for the stage-3 micro-classification; `thinkingConfig` with
   `thinkingBudget: 0` for `gemini-2.5-`/`gemini-3.x` prefixes; unknown models
   stay fail-closed.
4. The legacy keep-alive schedule failure (05:17 UTC, run 39405420165, "Require
   actual database credentials") came from the workflow version before the PR-#6
   merge (legacy secret names). With the current names all secrets are present;
   the Neo4j authentication itself is nevertheless broken (see above).
